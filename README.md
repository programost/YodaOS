**YodaOS** — 64-разрядная экспериментальная ОС для x86_64 с собственным ядром, драйверами VGA, клавиатуры, ATA (PIO), RTC, PC-спикера и поддержкой файловых систем ext2 и ramfs. Содержит встроенную командную оболочку с элементами BusyBox (заглушки), демонстрацию переключения в ring 3 и минимальный набор syscall.

## Состояние проекта

Проект является учебно-экспериментальным. Многие возможности реализованы в виде заглушек:
- **BusyBox**: только имитация команд через встроенные applet'ы ядра (реальных процессов нет).
- **Ring 3**: существует переключение в кольцо 3 через `iretq` и простейшая демо-задача, но многозадачность и защита памяти отсутствуют.
- **sh / source**: интерпретация скриптов — построчное чтение и вызов тех же встроенных команд; никакого «настоящего» шелла с подпроцессами нет.

## Основные компоненты

| Компонент          | Реализация                                                                 |
|--------------------|----------------------------------------------------------------------------|
| Загрузка           | MBR + stage2 + Multiboot2, переход в long mode, identity mapping первых 1GB |
| Файловые системы   | **ramfs** (монтирована в `/`) – до 320 КБ, иерархия каталогов, спецфайлы    |
|                    | **ext2** (монтирована в `/disk`) – блочная структура, косвенная адресация   |
| Драйверы           | VGA (текстовый режим 80×25, курсор, цвет), PS/2 клавиатура (scancode set 1) |
|                    | ATA PIO (LBA28, чтение/запись секторов), RTC (CMOS), PC Speaker            |
| Системные вызовы   | `int 0x80`: `1 = write` (вывод на VGA), `2 = getpid` (всегда 1)              |
| Командная оболочка | Примитивный CLI с историей, разбором аргументов, вызовом встроенных команд   |
| Редактор `ynan`    | Только для ext2-файлов (буфер 8 КБ)                                         |

## Сборка и запуск

### Требования
- `nasm` (>= 2.15)
- `x86_64-elf-gcc` (или любой GCC с поддержкой `-m64` и `-ffreestanding`)
- `ld` (поддержка ELF64)
- `qemu-system-x86_64` (рекомендуется)

### Сборка

```bash
# Пример для гипотетического Makefile
make all

# С чистым диском (создаст ext2 автоматически)
qemu-system-x86_64 -cdrom yodaos.iso -m 256M -vga std

# С существующим образом диска (P.S. мы советуем данный вариант потому что с созданием нового пустого диска нужно по возиться и там есть баги)
qemu-system-x86_64 -kernel kernel.elf -hda disk.img -m 256M
